## 🌟 Task 1: Simple E-Commerce Store (`AlphaStore`)

A cyber-luxury full-stack e-commerce web application with product listings, responsive filtering, quick-view modals, persistent shopping cart drawer, promo coupon discounts, multi-step checkout, and order history invoice generation.

- **Frontend:** Responsive storefront with dark luxury theme, Google Fonts (`Plus Jakarta Sans` & `Outfit`), glassmorphism cards.
- **Features:** Live search, category chips, price slider, in-stock toggle, promo codes (`CODEALPHA10`, `ALPHA20`, `FREESHIP`), multi-step checkout (Bag -> Shipping -> Payment -> Invoice).
- **Backend & Database:** Express.js REST API with file-backed atomic JSON database, bcrypt password hashing, and JWT token authentication.
- **Port:** Runs on `http://localhost:5000`
- **Full Guide:** Read [Task 1 README](./Task-1_Ecommerce_Store/README.md)

---

## 🌟 Task 2: Social Media Platform (`PulseAlpha`)

A responsive full-stack social media application featuring user profiles, interactive news feed, post creation with photo attachments & hashtags, heart like animations, comments system, and dynamic follower graph.

- **Frontend:** 3-Column layout (Navigation, Feed, Trending & Suggestions), interactive heart pop animations, inline comments accordion, profile dashboard.
- **Features:** Post composer with preset photo attachments, multi-tab feeds (For You, Following, Trending), like/unlike toggle, comments, follow/unfollow toggle, live counter updates.
- **Backend & Database:** Express.js REST API with zero-config persistent storage and JWT auth.
- **Port:** Runs on `http://localhost:5001`
- **Full Guide:** Read [Task 2 README](./Task-2_Social_Media_Platform/README.md)
